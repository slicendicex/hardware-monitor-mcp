# Журнал изменений

## v0.1 (пакет 0.1.0)

### Added

- Пять MCP-инструментов для разового измерения CPU, RAM, NVIDIA GPU, описания оборудования и последовательного снимка с UTC-меткой.
- Структурированные результаты, единицы измерения в названиях полей и причины недоступности датчиков.
- Локальная точка Streamable HTTP, модульные проверки psutil и NVML, интеграционный тест MCP и инструкции для Windows.

### Changed

Первый выпуск устанавливает исходный контракт инструментов. Предыдущей версии для сравнения нет.

### Fixed

При проверке первого выпуска уточнены аннотации возвращаемых словарей. Интеграционный тест подтвердил наличие structuredContent у всех пяти инструментов.

### Known limitations

- Учитывается первая NVIDIA GPU. Набор доступных датчиков зависит от Windows-драйвера.
- Частота CPU в Windows может быть номинальной. Температура CPU не собирается.
- Замеры в снимке последовательны. Метка UTC обозначает окончание сбора.
