# Дорожная карта Hardware Monitor MCP

Этот документ задаёт направление Local AI Lab. Концептуальные изменения согласуются с пользователем. Статус Completed означает выполнение критериев строки. Переход к реализации следующей версии требует отдельного указания.

| Version | Scope | Статус | Зависит от |
|---|---|---|---|
| v0.1 | Hardware telemetry snapshots and read-only MCP tools | Completed | Базовая версия |
| v0.2 | Continuous hardware monitoring | Planned | v0.1 |
| v0.3 | SQLite persistence and metrics history | Planned | v0.2 |
| v0.4 | LM Studio API integration | Planned | v0.1–v0.3 |
| v0.5 | Automated LLM benchmarking | Planned | v0.3 и v0.4 |
| v0.6 | Comparison of models and inference configurations | Planned | v0.5 |
| v1.0 | Complete local LLM research and observability toolkit | Planned | v0.1–v0.6 |

| Версия | Цель и границы | Основные задачи | Критерии готовности |
|---|---|---|---|
| v0.1 | Получить локальный снимок Windows по запросу через MCP | Собрать CPU, RAM и NVIDIA GPU, описать систему, объединить показания с UTC-меткой | На Windows получены показания оборудования. Локальный smoke-тест вызывает все пять read-only инструментов и проверяет структурированный JSON и UTC. Тесты покрывают отсутствие GPU и отказ датчика. |
| v0.2 | Наблюдать изменения показателей в течение сеанса, в памяти процесса | Организовать периодическую выборку, определить интервал и жизненный цикл сбора | За сеанс получена последовательность замеров с UTC. Сбор корректно останавливается, недоступность датчика обработана, разовый снимок сохраняет контракт. |
| v0.3 | Читать историю замеров после перезапуска | Определить схему SQLite, сохранять выборки и читать их за период | После перезапуска запрос за период возвращает сохранённые значения, единицы, время и пропуски датчиков. |
| v0.4 | Связать аппаратные наблюдения с локальной LM Studio через её API | Определить поддерживаемые вызовы API, получить сведения о модели, обработать недоступность сервиса | Интеграция проверена на локальной LM Studio. Отключение LM Studio сохраняет доступ к аппаратной телеметрии. |
| v0.5 | Автоматически воспроизводить один сценарий бенчмарка LLM | Определить входные условия, выполнять сценарий и связывать результат с телеметрией прогона | Повторный запуск по сохранённым условиям даёт отдельный результат с моделью, конфигурацией, измерениями и статусом прогона. |
| v0.6 | Сопоставлять результаты моделей и конфигураций инференса | Выбирать сопоставимые прогоны, показывать различия условий и метрик | Для двух прогонов можно установить, что менялось и как различаются метрики. Несопоставимые условия явно видны. |
| v1.0 | Объединить реализованные версии в локальный исследовательский комплект | Проверить сквозной сценарий и подготовить воспроизводимое руководство | На целевой Windows по руководству воспроизведён путь от сбора телеметрии до сравнения результатов, пройдены регрессионные проверки и описаны ограничения. |
