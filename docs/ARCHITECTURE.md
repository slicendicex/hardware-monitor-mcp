# Архитектура v0.1

## Путь запроса

Локальный MCP-клиент обращается к `http://127.0.0.1:8765/mcp`. Предусмотренный внешний маршрут проходит от ChatGPT через OpenAI Secure MCP Tunnel и Windows tunnel-client к той же точке. Сервер FastMCP использует stateless Streamable HTTP с JSON-ответами. Каждый вызов инициирует собственное чтение датчиков. Результат возвращается в `structuredContent`; состояние между вызовами не требуется.

## Компоненты и инструменты

Все модули расположены в `src/hardware_monitor/`. Сборщики возвращают обычные словари, что позволяет проверять измерения независимо от транспорта.

| Модуль | MCP-инструмент | Источник и ответственность |
|---|---|---|
| cpu.py | get_cpu_stats | psutil измеряет загрузку каждого логического CPU за 200 мс. Общая загрузка — среднее этой выборки. Отдельно читаются число физических и логических ядер и частота в MHz. |
| memory.py | get_ram_stats | Один вызов virtual_memory даёт согласованный набор total_mib, used_mib, available_mib и utilization_percent. |
| gpu.py | get_gpu_stats | Инициализирует NVML, читает карту с индексом 0, освобождает NVML после чтения. Возвращает имя, загрузку, объёмы VRAM, температуру и мощность. |
| system.py | get_system_info | Объединяет модель CPU, ядра, объёмы RAM и VRAM, модель GPU, семейство и выпуск ОС и версию Python. В Windows модель CPU берётся из фиксированного значения реестра ProcessorNameString. |
| readings.py | Внутренний модуль | Содержит коэффициент перевода байтов в MiB и общий обработчик недоступных значений. |
| server.py | get_snapshot | Регистрирует пять функций без аргументов. Последовательно вызывает CPU, RAM и GPU и ставит метку времени по завершении. |

## Контракт телеметрии

В снимке ключи `cpu`, `ram` и `gpu` содержат полные ответы соответствующих сборщиков. Внутри ответа GPU ключ `gpu` содержит объект карты либо null. Поле `timestamp_utc` содержит строку ISO 8601 со смещением +00:00. Снимок охватывает интервал последовательного чтения.

Память выражена в MiB (2²⁰ байт), температура в °C, мощность и её предел в W. NVML возвращает мощность в милливаттах, сборщик делит её на 1000. Поле `memory_utilization_percent` отражает долю времени активности памяти по NVML, а `vram_used_percent` вычисляется из занятого и общего объёма VRAM.

Если источник сообщает об ожидаемой ошибке, соответствующее значение становится null, а словарь `unavailable` связывает поле с причиной. Отсутствие карты или ошибка инициализации NVML отражается на уровне объекта GPU. Отказ отдельного датчика оставляет остальные доступные поля в ответе. В нормальном ответе словарь причин пуст.

## Граница доступа

Привязка к IPv4 loopback ограничивает сетевую доступность. Доступные операции задаются явной регистрацией пяти функций только для чтения, каждая помечена readOnlyHint. Клиент не передаёт команды, пути или имена ключей реестра. Состав системных полей фиксирован и исключает имя пользователя, имя машины и сетевые адреса. Туннель работает отдельным процессом Windows. Запланированные компоненты перечислены в [дорожной карте](../ROADMAP.md).
