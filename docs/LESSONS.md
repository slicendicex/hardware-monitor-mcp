# Инженерные уроки

| ID | Problem | Context | Resolution / Workaround | Verification | Applicability |
|---|---|---|---|---|---|
| L-01 | Windows pip получает HTTP 407 при загрузке зависимостей. | У WSL был рабочий доступ к PyPI через прокси. | В WSL подготовить .wheelhouse для win_amd64, CPython 3.14, ABI cp314. Включить зависимости Windows (pywin32, colorama) и сборки (setuptools из pyproject.toml). В Windows выполнить команду ниже. | В ходе подготовки MVP Codex скачал Windows wheels через WSL и установил проект из них в Windows .venv. | Повторная установка на той же платформе при недоступности PyPI из Windows. |
| L-02 | При старте появляется IncompleteFieldDefinitionWarning для lifespan. | Предупреждение исходит из pydantic-settings при загрузке SDK. | Для закреплённых версий проверить запуск и вызовы инструментов, сохранить предупреждение в результатах. | Ранее Codex получил 6 passed, 1 warning под Windows, включая MCP smoke-тест. | При смене SDK или pydantic-settings повторить проверку. |
| L-03 | Успешный тест в WSL оставляет открытым вопрос о показаниях Windows. | Mock-тесты проверяют обработку значений, реальные показания зависят от ОС и драйвера. | Запустить Windows Python и вызвать сборщики на целевом хосте. | Codex ранее прочитал реальные датчики в Windows. Пользователь отдельно подтвердил CPU, RAM и GPU через ChatGPT. | При приёмке и после смены драйвера или среды. |
| L-04 | Два процента памяти GPU могут сильно расходиться. | NVML измеряет активность памяти за интервал, объём занятой VRAM отражает заполнение. | Для активности читать memory_utilization_percent, для заполнения — vram_used_percent. | В test_gpu_partial при активности 7% и занятом 1 из 4 MiB ожидаются 7% и 25%. | Подписи метрик и сверка с внешним монитором. |
| L-05 | Единая метка snapshot может создать впечатление одновременного замера. | get_snapshot последовательно вызывает CPU, RAM и GPU. | Трактовать timestamp_utc как момент окончания сбора. | Порядок подтверждён чтением server.py. Smoke-тест отдельно проверяет смещение UTC. | Сопоставление показаний при быстро меняющейся нагрузке. |
| L-06 | После изменения MCP-интерфейса в ChatGPT может остаться прежний список инструментов. | Локальный tools/list проверяет только сервер. | После изменения интерфейса обновить список инструментов подключения в ChatGPT, сравнить его с tools/list и вызвать изменённый инструмент. | Пользователь подтвердил обнаружение и вызов 5/5 для v0.1. Сценарий со сменой схемы отдельно не проверялся. | При добавлении, переименовании или изменении схемы инструмента. |

Установка из подготовленного wheelhouse для L-01, из корня проекта в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install --no-index --find-links=.wheelhouse -c requirements-win314.txt -e ".[test]"
```
