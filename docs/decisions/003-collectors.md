# ADR-003 — Сборщики отделены от MCP-интерфейса

| Поле | Значение |
|---|---|
| Date | 2026-11-25 (дата фиксации решения v0.1) |
| Status | Accepted |
| Context | Данные поступают из psutil, NVML и средств ОС. Проверка отказов датчиков требует подмены источников в тестах. |
| Alternatives | Сравнение альтернатив в материалах проекта не зафиксировано. |
| Decision | Сборщики возвращают словари Python. Регистрация инструментов, транспорт и сборка снимка находятся в server.py. |
| Rationale | Модули измерения можно вызывать и тестировать независимо от транспорта. |
| Consequences | Контракт данных проверяется тестами сборщиков, а выдача structuredContent — через MCP-клиент. |
| Related files | [Архитектура](../ARCHITECTURE.md), [тесты сборщиков](../../tests/test_collectors.py), [smoke-тест](../../tests/test_mcp.py) |
